<details class="change-entry"><summary>Repeated Waitlist signup returns the existing enrollment <span class="entry-status">1 focused checks · Qase: Partial</span></summary>

#### What changed

An unchanged signup can return the existing pending Waitlist enrollment instead of preparing a second purchase. The server checks the original Customer, ticket, quantity, subscriber and effective payment type; changed or duplicate enrollments are rejected. This is separate from fulfilling a Waitlist offer.

**Setup and limits:** Requires the same unpurchased Waitlist basket and one pending subscriber. It is not permission to retry an uncertain paid order without checking its result.
