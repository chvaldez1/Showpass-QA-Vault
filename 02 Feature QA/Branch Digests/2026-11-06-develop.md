# Showpass branch digest — November 6

The main risk is existing purchases, money, Inventory and admission being affected by changes in shared code. The new integration and interface work is grouped below so you can scan it quickly.

Backend develop vs master · Frontend develop vs main. Source snapshot: November 6, 2026, 11:53 a.m. America/Edmonton. This is a rewrite of that snapshot; code and Jira were not re-collected.

**Testing split:** Feature acceptance testing belongs to the teams owning each change. The whole QA team shares the regression pack at the end; divide its checks across testers and clients rather than having everyone repeat the full pack.
