### Checkout, purchases and returns

<a id="change-12"></a>

<details class="change-entry"><summary>Voucher Refunds restore combined uses across refunded order lines <span class="entry-status">6 linked checks · Qase: Needs review</span></summary>

#### What changed

When a Refund includes several order lines that used the same voucher, their uses are combined and added back to the voucher allowance on a freshly locked record. The cached balance is cleared after commit. This Refund change does not restore voucher uses for Dashboard Void.

**Setup and limits:** Requires enable_voucher_refund_limit_fix. The previous path remains when the switch is off. No live voucher balance or refund was changed, and switch state is unknown.
