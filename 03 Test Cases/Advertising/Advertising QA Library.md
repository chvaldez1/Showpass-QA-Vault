# Advertising QA Library

Checkout ads and marketing event delivery have different proof. A visible placement and a provider receiving an event are two checks. [[03 Test Cases/Test Cases by Feature|Test library]]

## Setup and proof

Use one approved test Organization, an eligible purchase or basket and known consent and tracking settings. Match the actual placement or provider event to the intended order and distinguish it from a fresh reload.
