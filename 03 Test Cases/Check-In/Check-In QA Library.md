# Check-In QA Library

The Dashboard Check-in entry and the older Check In cases cover admission and pickup on specific UI variants. [[03 Test Cases/Test Cases by Feature|Test library]]

## Setup and proof

Start with the intended Event occurrence and an issued test ticket. Match the exact item, admission state and history after the action. Track the employee's role, and use an independent ticket for a transfer or void branch.
